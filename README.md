# F&P
Welcome to the F&P Healthcare repository.

F&P Healthcare is a project that showcases the IT operations, support processes, and documentation used to manage technology within a healthcare organisation. The repository has been created to demonstrate how IT teams support employees, maintain secure systems, and deliver reliable technology services across the business.

The documentation covers the complete employee lifecycle—from onboarding new staff and configuring devices to managing user accounts, Microsoft 365 administration, security, asset management, and employee offboarding. It also includes standard operating procedures (SOPs), IT checklists, troubleshooting guides, and best practices that help ensure consistency, efficiency, and security in everyday IT operations.

This project serves as a practical portfolio, reflecting real-world IT support and systems administration workflows while following professional documentation standards commonly used in healthcare environments.

Features
Employee onboarding and offboarding
Microsoft 365 and user account administration
Laptop and mobile device setup
IT support documentation and SOPs
Security and access management
Asset management
Troubleshooting guides
Knowledge base articles
Purpose

The aim of this repository is to demonstrate practical IT support, documentation, and service management skills through structured, real-world workflows. It is intended as a learning resource and professional portfolio that reflects industry best practices while containing no confidential or proprietary organisational information.
