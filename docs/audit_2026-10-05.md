# ScamShield audit pass — 5 October 2026

## Implemented

- Added shared dark design tokens and replaced bright white interface surfaces across the scanner, result panel, evidence lab and dashboard.
- Moved public statistics and synthetic scenario distribution into a compact, explicitly labelled background-context disclosure on the scanner.
- Corrected the dashboard explanation so it agrees with the measured confusion matrix and metrics.
- Kept the measured TF-IDF-only comparator and documented its fixed-threshold provenance instead of describing it as pending.
- Changed “Verified public case sources” to “Supporting guidance and public examples” and separated the fictional scenario organisation from the supporting guidance source.
- Added supporting-text controls to result explanations. Where an exact excerpt is unavailable, the interface says so instead of inventing one.
- Added a user-controlled attack journey stepper with previous, next and reset controls; the information remains available without relying on autoplay.
- Added a local logo source register and usage boundary in `docs/logo_sources.md`.

## Evidence basis

The dashboard reads `data/evaluation_results.json`: 12 held-out messages, 7 legitimate and 5 phishing, evaluated on 5 October 2026 with model `contextual-baseline-v5` at a 36/100 threshold. The perfect result is limited to this small hand-curated split and is not a claim of real-world reliability. The separate 24-message development regression set is labelled as non-independent after known failures were corrected. Synthetic demonstration counts, case-level screening scores and public background figures remain separate.

## Remaining limitations

- The latest logo pass removes decorative logo plates throughout the homepage and Evidence Lab. Lloyds now uses the transparent horse mark; Premier League and NHS retain their official local marks. Leeds Beckett uses a readable organisation-name fallback because an official reversed asset was not available locally without recolouring or inventing the mark.

- The evaluation set is too small for dependable scenario-level rates; the dashboard shows individual case scores but explicitly avoids scenario-level accuracy claims.
- The link inspector is a local pattern check only. It does not visit URLs, check reputation or use live threat intelligence.
- Browser OCR is a client-side dependency and can fail on unclear screenshots; manual review remains available.
- Brand assets require final rights/usage confirmation before any non-academic public launch.
