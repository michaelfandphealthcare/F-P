# Ethics and Scope

ScamShield is a controlled academic prototype. It will use public or fictional messages only and will not connect to personal email accounts, banking systems or live links.

The project will not create or distribute live phishing campaigns. Any AI-rewritten test material will be made from safe examples and used only for controlled evaluation. It will not contain real credentials, real victims or operational payment instructions.

The system will not claim certainty. It will recommend independent verification and will explain that a prediction is not proof. If participants are recruited for usability testing, the work must follow the university ethics process before recruitment begins. If approval or participants are unavailable, the evaluation will use a documented expert-review rubric instead.
