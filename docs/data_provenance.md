# ScamShield dashboard data provenance

The dashboard deliberately uses two different kinds of evidence:

1. **Public evidence**: figures taken from named, publicly available UK sources. These figures provide context for why the problem matters. They are not model-performance results.
2. **Synthetic research scenarios**: fictional messages and controlled categories created for this dissertation. These are used to test the prototype safely. They must never be presented as national crime statistics or as evidence that a named bank, university or football club was breached.

## Why this distinction matters

Using a real organisation's name without a verified source could create an inaccurate or unfair claim. A high-quality dissertation makes the boundary visible. The final report should state exactly which values are official context and which values were generated by the experiment.

## Current public sources

- Home Office, [Fraud Strategy 2026 to 2029](https://www.gov.uk/government/publications/fraud-strategy-2026-to-2029)
- Office for National Statistics, [Fraud and computer misuse in England and Wales: year ending March 2025](https://www.ons.gov.uk/peoplepopulationandcommunity/crimeandjustice/articles/fraudandcomputermisuseinenglandandwales/yearendingmarch2025)
- National Cyber Security Centre, [Spot scams](https://www.ncsc.gov.uk/collection/phishing-scams/spot-scams)

The values shown in `data/public_evidence.json` must be checked against the source pages again before final submission and cited in the dissertation bibliography.

## How the research data should evolve

During the project, replace the demonstration arrays in `data/dashboard_scenarios.json` with values generated from the final, versioned test set. Record:

- number of messages in each category;
- how each message was sourced or authored;
- whether it is legitimate, phishing or AI-rewritten;
- the warning signals present;
- the date and script version used to calculate the chart;
- the exact evaluation split used for model results.

This gives the dashboard research value rather than making it a decorative graphic.
